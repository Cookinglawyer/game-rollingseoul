# 서울 건물 다 따먹기

서울 실제 지도 위에서 캐릭터가 공을 굴려 작은 물건부터 건물까지 붙여 나가는 괴혼 스타일 게임.
실제 지도의 건물이 장난감 블록처럼 되어 있어서, 공이 커지면 건물도 통째로 공에 붙는다.

## 실행

빌드 과정 없음. 정적 서버만 있으면 됩니다. (`index.html` 더블클릭은 브라우저 보안 정책 때문에 동작하지 않음)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 조작

| 키 | 동작 |
|---|---|
| W / ↑ | 앞으로 |
| S / ↓ | 뒤로 |
| A D / ← → | 방향 전환 |
| Esc / P | 일시정지 |
| 휴대폰 | 화면을 누른 채 드래그 (조이스틱) |

## 규칙

- 공 지름의 80%보다 작은 물건·건물은 닿으면 붙는다. 붙일수록 공이 커진다.
- 너무 큰 것은 튕겨 낸다. 커지면 "이제 ○○도 먹을 수 있다!" 알림이 뜬다.
- 건물 크기 = (바닥 길이와 높이 중 큰 쪽) × 0.65. 예: 교보생명빌딩 약 57m → 공 71m부터.
- 제한 시간 안에 **목표 크기**에 도달하면 클리어. 다음 스테이지가 열린다.
- 오른쪽 위: 목표까지 진행률(로그 비율)과 먹은 건물 수.
- 오른쪽 아래 미니맵: 분홍 = 지금 먹을 수 있는 건물·물건.

## 구조

```
index.html            화면 구성 (타이틀, 스테이지 선택, 브리핑, 게임, 결과)
src/main.js           화면 전환, 저장(localStorage), 타이틀 배경 애니메이션
src/stages.js         스테이지 목록과 설정 (시간, 시작 크기, 지도 파일)
src/game/Game.js      게임 루프: 공 굴리기, 흡수(물건·건물), 카메라, HUD, 승패
src/game/player.js    공을 미는 캐릭터 (5등신 블록 인형, 검은 반팔티·형광 연두 반바지, 키 16cm 고정)
src/game/props.js     먹잇감 30여 종의 모델과 크기
src/game/world.js     지도 JSON → 블록 건물/도로/광장 3D, 충돌, 이동 가능 영역
src/game/input.js     키보드 + 터치 조이스틱
src/game/audio.js     효과음 (Web Audio로 합성, 파일 없음)
vendor/               Three.js r170 (MIT)
tools/fetch_osm.py    OpenStreetMap → data/<구역>.json 변환
tools/regions.json    구역별 범위 (지도 범위, 놀이 범위, 시작점)
data/                 변환된 지도 데이터
```

## 지도 데이터 만들기

```bash
python3 tools/fetch_osm.py gwanghwamun
```

Overpass API(overpass-api.de)에서 `tools/regions.json`의 범위를 받아 `data/gwanghwamun.json`을 만든다.
지도 파일이 없으면 게임은 건물 없는 테스트용 빈 광장으로 실행된다.

서버에서 Overpass 접속이 안 될 때는 브라우저로 받은 파일을 변환만 할 수 있다.

1. [overpass-turbo.eu](https://overpass-turbo.eu)에 `tools/fetch_osm.py`의 `build_query()` 쿼리를 넣고 실행
2. 내보내기(Export) → raw OSM data 다운로드
3. `python3 tools/fetch_osm.py gwanghwamun --raw export.json`

현재 `data/gwanghwamun.json`은 2026-10-28 OSM 데이터(건물 428, 도로 326, 광장·녹지 103, 가로수 138)로 만들었다.
지하 시설(`layer`/`level` 음수, 예: 세종이야기)은 제외하고, 조선 건축 태그가 있는 건물(광화문, 동십자각 등)은 전통 건물 색으로 그린다.

- 건물: 외곽선 + 높이(`height` → `building:levels` × 3.3m → 기본값 14m)
- 도로: 중심선 + 폭(`lanes` × 3.3m 또는 도로 등급별 기본값)
- 광장/공원/물, 가로수(`natural=tree`, `tree_row`)

## 밸런스 메모

- 흡수 시 성장: `지름³ += 2.6 × 물건크기³`, 건물은 `0.8 × 건물크기³` (`Game.js`의 `GROWTH`, `BUILDING_GROWTH`)
- 이동 속도: `1.5 + 3.0 × 지름^0.85` m/s (100m 공 ≈ 150m/s)
- 물건은 크기 등급별로 시작점에서 정해진 거리 안에 놓인다 (`Game.js`의 `TIER_RANGE`)
  그리고 반지름 4.5m 공이 시작점에서 갈 수 있는 곳에만 놓인다 (2m 격자 이동 가능 영역).
- 공이 커지면 벽과 부딪히는 몸통은 겉보기의 60%까지 작아진다. 큰 건물 사이 골목에도 들어가
  안쪽의 작은 건물을 먹을 수 있게 하려는 것 (대신 큰 건물에 살짝 파고들어 보인다).
- 양쪽 벽에 깊이 끼면 충돌 반지름을 잠깐 줄여 빠져나오게 한다.
- 붙은 물건은 붙은 자리에 그대로 남고, 공 속(core, 겉보기 반지름의 70%)이 커지면서 오래된 것부터 묻힌다.
  완전히 묻힌 것은 지워서 최대 700개만 유지. 절반은 바깥으로 꽂힌 방향, 절반은 바닥에 있던 모양 그대로 붙는다.
- 캐릭터 키는 16cm 고정. 공이 커지면 공 아래에 가려져 안 보인다.
- 길찾기 자동 봇 기준: 10cm → 12m 약 270초, 12m → 150m 약 150초 (건물 약 190/277개, 실행마다 차이 큼).
  1스테이지 목표 150m, 제한 9분. 전부 먹으면 약 194m.
