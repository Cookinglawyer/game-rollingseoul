# 서울 건물 다 따먹기

서울 실제 지도 위에서 공을 굴려 작은 물건부터 건물까지 붙여 나가는 괴혼 스타일 게임.

## 실행

빌드 과정 없음. 정적 서버만 있으면 됩니다.

```bash
cd seoul-katamari
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 현재 구현 (v0.1)

- 타이틀 화면 (START 버튼, Enter/Space 키 지원, 배경 애니메이션)
- 스테이지 선택 화면 (7개 스테이지, 순차 해금, 클리어 기록은 localStorage에 저장)
- 스테이지 브리핑 화면 (시작/목표 크기, 제한 시간)
- 스테이지 데이터: `src/stages.js` (각 스테이지의 실제 좌표 범위 `bbox` 포함)

## 다음 단계

1. Three.js 도입, 게임 플레이 화면 (공 굴리기, 카메라, 타이머)
2. 지도 데이터 파이프라인: OSM(Overpass API) → 스테이지별 JSON
   - 건물 외곽선 + 높이(`height` / `building:levels`) → 건물 하나당 메시 하나로 압출
   - 도로, 공원, 물, 가로수
3. 소품 배치: 도로에는 자동차, 인도에는 사람, 공원에는 나무 (데이터에 없는 작은 물건은 규칙에 따라 생성)
4. 크기별 흡수 규칙 + 붙은 물체가 공 모양을 바꾸는 처리
5. 최종 스테이지(서울 전체)용 LOD, 청크 단위 로딩
