# 서울 건물 다 따먹기

서울 실제 지도 위에서 캐릭터가 공을 굴려 작은 물건부터 건물까지 붙여 나가는 괴혼 스타일 게임.
실제 지도의 건물이 우리 동네 빌라·상가 건물 모습으로 서 있고, 공이 커지면 건물도 통째로 공에 붙는다.

## 실행

빌드 과정 없음. 정적 서버만 있으면 됩니다. (`index.html` 더블클릭은 브라우저 보안 정책 때문에 동작하지 않음)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

| 키 | 동작 |

## 규칙

- 공 지름의 80%보다 작은 물건·건물은 닿으면 붙는다. 붙일수록 공이 커진다.
- 너무 큰 것은 튕겨 낸다. 커지면 "이제 ○○도 먹을 수 있다!" 알림이 뜬다.
- 건물 크기 = (바닥 길이와 높이 중 큰 쪽) × 0.65. 예: 교보생명빌딩 약 57m → 공 71m부터.
- 제한 시간 안에 **목표 크기**에 도달하면 클리어. 다음 스테이지가 열린다.
- 오른쪽 위: 목표까지 진행률(로그 비율)과 먹은 건물 수.
- 오른쪽 아래 미니맵: 분홍 = 지금 먹을 수 있는 건물·물건.
- 이름이 있는 건물은 위에 말풍선으로 이름이 뜬다 (공 근처 가까운 20개, 분홍 = 지금 먹을 수 있음, 멀수록 흐리게).
  보이는 거리는 공이 클수록 넓어진다 (`max(120m, 공 지름 × 8)`).


## 지도 데이터 만들기

```bash
python3 tools/fetch_osm.py gwanghwamun
```

Overpass API(overpass-api.de)에서 `tools/regions.json`의 범위를 받아 `data/gwanghwamun.json`을 만든다.
지도 파일이 없으면 게임은 건물 없는 테스트용 빈 광장으로 실행된다.

서버에서 Overpass 접속이 안 될 때는 브라우저로 받은 파일을 변환만 할 수 있다.

1. [overpass-turbo.eu](https://overpass-turbo.eu)에 `tools/fetch_osm.py`의 `build_query()` 쿼리를 넣고 실행
2. 내보내기(Export) → raw OSM data 다운로드
3. `python3 tools/fetch_osm.py gwanghwamun --raw export.json`

현재 `data/gwanghwamun.json`은 2026-10-30 OSM 데이터로 만들었다.
범위 약 1,240m × 1,600m (경복궁 근정전 ~ 서울시청·서울광장, 서촌 동쪽 ~ 인사동 입구):
건물 2,506(놀이 구역 안 2,089), 도로 1,104, 광장·녹지 367, 가로수 523. 세종대왕·이순신 동상 위치 포함.
지하 시설(`layer`/`level` 음수, 예: 세종이야기)과 고가 역사(`building=train_station`이면서 `layer` 1 이상, 예: 성수역)는 제외하고, 조선 건축 태그가 있는 건물(광화문, 동십자각 등)은 전통 건물 색으로 그린다.

- 건물: 외곽선 + 높이(`height` → `building:levels` × 3.3m → 기본값 14m)
- 도로: 중심선 + 폭(`lanes` × 3.3m 또는 도로 등급별 기본값)
- 광장/공원/물, 가로수(`natural=tree`, `tree_row`)

## 밸런스 메모

- 흡수 시 성장: `지름³ += 2.6 × 물건크기³`, 건물은 `0.8 × 건물크기³` (`Game.js`의 `GROWTH`, `BUILDING_GROWTH`)
- 이동 속도: `1.5 + 3.0 × 지름^0.85` m/s (100m 공 ≈ 150m/s)
- 물건은 크기 등급별로 시작점에서 정해진 거리 안에 놓인다 (`Game.js`의 `TIER_RANGE`)
  그리고 반지름 4.5m 공이 시작점에서 갈 수 있는 곳에만 놓인다 (2m 격자 이동 가능 영역).
- 공이 커지면 벽과 부딪히는 몸통은 겉보기의 60%까지 작아진다. 큰 건물 사이 골목에도 들어가
  안쪽의 작은 건물을 먹을 수 있게 하려는 것 (대신 큰 건물에 살짝 파고들어 보인다).
- 양쪽 벽에 깊이 끼면 충돌 반지름을 잠깐 줄여 빠져나오게 한다.
- 벽에 부딪힌 프레임은 실제로 움직인 거리로 속도를 다시 계산한다 (모서리에 끼어 제자리에서 헛돌지 않게).
- 붙은 물건은 붙은 자리에 그대로 남고, 공 속(core, 겉보기 반지름의 70%)이 커지면서 오래된 것부터 묻힌다.
  완전히 묻힌 것은 지워서 최대 700개만 유지. 절반은 바깥으로 꽂힌 방향, 절반은 바닥에 있던 모양 그대로 붙는다.
- 캐릭터 키는 16cm 고정. 공이 커지면 공 아래에 가려져 안 보인다.
- 인파 약 2,400명(인도·광화문 광장), 차량 약 900대(도로를 따라 오른쪽 차선 주행, 20%는 갓길 주차).
  시작점 20m 안에는 두지 않는다 (`Game.js`의 `START_CLEAR`).
- 시작점 400m 안에 작은 건물(크기 20m 미만)이 150개보다 적으면(아파트·초고층 위주 지도) 편의점·컨테이너 사무실·정자·타워크레인
  같은 중간 크기 소품을 6배로 늘린다 (`props.js`의 `filler`). 20~60m 구간에서 먹을 게 없어 멈추지 않게 하려는 것.
- 150m 넘는 초고층은 넘는 부분을 40%만 크기로 친다. 롯데월드타워(555m)는 공 254m부터, 63빌딩은 155m부터.
- 방향 전환: 최대 초당 1.3라디안(약 75°), 누르면 서서히 빨라진다 (`Game.js`의 `TURN_RATE`).

## 건물 외관

`src/game/facades.js`. 지도 건물의 높이·면적으로 종류를 고른다.

- 높이 정보가 없는 건물(OSM 기본값 14m)은 3~5층으로 바꾼다.
- 30m 이상 아파트(`building=apartments`·`residential`): 흰색·베이지 외벽
- 그 밖의 30m 이상: 유리 커튼월 오피스 또는 회색 타일 근린생활 건물
- 그 밖: 붉은 벽돌 빌라, 베이지 타일 빌라, 흰 외벽 상가주택, 회색 타일 근린생활 건물
- 1층 상가(간판 + 진열창/셔터), 세로 간판, 초록 방수 옥상, 물탱크·옥탑방
- 전통 건축 태그: 흰 벽·나무 기둥·기와 지붕 한옥
- 모든 무늬는 텍스처 한 장(아틀라스)에 모으고, 셰이더에서 칸 안 반복(fract)을 처리해 건물 하나 = 메시 하나

## 랜드마크

`src/game/landmarks.js`. 실제 비율·색을 참고해 기본 도형으로 만든 모델이며, 건물처럼 먹을 수 있다.

- 광화문, 기념비전: 지도 데이터의 같은 이름 건물을 외곽선 크기·방향에 맞춘 모델로 바꾼다.
- 세종대왕 동상, 이순신 장군 동상: 지도 데이터의 동상 지점(`points`)이 있으면 그 위치, 없으면 기본 경위도.
- 거북선: 이순신 장군 동상 남쪽 11m.
- 길찾기 자동 봇 기준 (확장 지도, 인파·차량 추가 후, 먹을 수 있는 건물을 우선): 12m 약 210초, 100m 약 415초,
  250m 약 525초 (건물 약 1,300/2,089개). 1스테이지 목표 250m, 제한 12분. 실행마다 차이가 크다.
